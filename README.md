# CapitalFarm

**Kalkulator Modal & Keuntungan Usaha Agribisnis**

CapitalFarm adalah platform kalkulasi modal dan keuntungan untuk petani dan peternak di Indonesia. Tersedia 3 sektor utama:

- **Perikanan** — Budidaya ikan lele: hitung modal bibit, pakan, kolam, estimasi panen
- **Perkebunan** — Hitung modal lahan, bibit, perawatan, estimasi hasil panen
- **Peternakan** — Hitung modal ternak, pakan, kandang, estimasi keuntungan

Dibangun dengan Laravel 12, Blade, Tailwind CSS v4, dan Vite. Mobile-first, dark mode, dan gratis selamanya.

## Fitur

- **Gratis** — Semua fitur tanpa biaya tersembunyi
- **Akurat** — Kalkulasi berdasarkan harga pasar dan standar biaya operasional Indonesia
- **Mudah** — UI intuitif, tanpa perlu paham akuntansi
- **Mobile-first** — Responsive, nyaman di HP
- **Dark mode** — Toggle light/dark, auto-detect preferensi sistem

## Tech Stack

| Lapisan | Teknologi |
|---|---|
| Backend | Laravel 12 (PHP) |
| Frontend | Blade + Tailwind CSS v4 |
| Build Tool | Vite + @tailwindcss/vite |
